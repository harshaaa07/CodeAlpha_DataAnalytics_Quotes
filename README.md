# CodeAlpha Data Analytics Internship Project

## Completed Tasks
This project completes **3 of the 4 tasks**, satisfying the internship instruction to complete any 2 or 3 tasks.

1. **Task 1 — Web Scraping**
   - Scrapes quotes, authors, and tags from Quotes to Scrape.
   - Saves the collected dataset as `data/quotes_dataset.csv`.

2. **Task 2 — Exploratory Data Analysis (EDA)**
   - Checks structure, data types, missing values, duplicates, descriptive statistics, authors, tags, and potential anomalies.
   - Creates an enriched dataset at `outputs/eda_enriched_quotes.csv`.

3. **Task 3 — Data Visualization**
   - Creates four charts:
     - Word-count distribution
     - Top 10 authors
     - Top 10 tags
     - Quote length vs. word count

## Installation

```bash
pip install requests beautifulsoup4 pandas matplotlib
```

## Run

```bash
python src/task1_web_scraping.py
python src/task2_eda.py
python src/task3_visualization.py
```

Run the scripts in this order because Tasks 2 and 3 use the output of the previous task.
